# Spagogo Order App

A lightweight order form for Fatima Spagogo, a local food delivery business. 
Customers fill out their order details, which are automatically formatted 
into a WhatsApp message and sent directly to the business.

**Live demo:** [(https://lustrous-meerkat-6dc043.netlify.app/)]

## Built with
- HTML/CSS/JavaScript
- WhatsApp Click-to-Chat API integration

## Features
- Dynamic order form with menu selection
- Auto-generates a pre-filled WhatsApp message
- Responsive, branded styling
